# CV / resume

Upload a 1–2 page research CV to every portal. Keep one master file and export PDF per school if you want a school-specific faculty line.

## Suggested sections

1. Education
2. Research experience (problem, method, result, advisor)
3. Publications and preprints
4. Talks / posters
5. Teaching
6. Awards
7. Skills (languages, frameworks, theory tools)
8. Service (optional)

## Notes

Some portals ask for a specific header (name, document type, program) or a personal website link — follow each school's instructions when exporting PDF.
